#🌿 HGY AHŞAP TANITIM WEB SİTESİ

##📌 PROJE HAKKINDA
HGY Ahşap için geliştirilen bu web sitesi, markanın üretmiş olduğu ahşap ürünleri dijital ortamda etkili ve estetik bir şekilde tanıtmak amacıyla hazırlanmıştır.
Bu proje bir e-ticaret platformu değildir. Amaç; ürünlerin satışından ziyade, marka kimliğini yansıtmak ve ürünleri görsel olarak ön plana çıkarmaktır.

##🧸 ÜRÜN KATEGORİLERİ
Ahşap oyuncaklar
Ahşap süs eşyaları
Ahşap mutfak ürünleri

##🚀 KULLANILAN TEKNOLOJİLER
HTML5
CSS3

Tamamen temel web teknolojileri kullanılarak geliştirilmiştir.
Herhangi bir framework veya kütüphane kullanılmamıştır.
